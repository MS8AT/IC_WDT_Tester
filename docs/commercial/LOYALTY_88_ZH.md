# 附件1：白俄罗斯企业忠诚客户计划条款

## 目的

MS8AT GLOBAL 提供折扣，以降低白俄罗斯企业获得咨询及自动化支持的成本。这是服务方商业计划，不是政府优惠、财政补贴或免税措施。

## 2.1

适用客户为在白俄罗斯注册、为自身经营订购服务的法人。依据为已签合同中的客户资料及登记信息。

## 2.2

折扣为基准小时费率的88%，适用于合同项下咨询、信息服务、流程分析、软件自动化配置及支持。

## 2.3

所有符合2.1条的客户适用相同条件。除书面另有约定外，不叠加折扣。享受优惠小时费率无需购买独立自动化项目。

## 2.4

设备、付费第三方许可、云资源、差旅及单独固定报价项目不自动适用折扣，其价格及可能折扣在相应订单或单独合同中约定。

## 3. 费率及计算

基准：272.51 BYN/小时。折扣88%，应付比例12%。四舍五入后优惠费率为32.70 BYN/小时。计算：272.51 × 0.12 = 32.7012 BYN → 32.70 BYN。每小时四舍五入后优惠239.81 BYN。

## 计算（续）

订单采用已四舍五入的32.70 BYN小时费率，实际分钟费用按合同3.2条计算。适用增值税包含在价格中并在文件中列明。本附件不设独立税收优惠。

## 4.1

对具体客户，本附件自合同签署起生效并在合同期内有效。变更无追溯力，不提高已约定订单价格。

## 4.2

计划新条件适用于新合同或双方书面约定。汇率变动本身不改变固定BYN费率。

## 4.3

实施前，服务方通过内部决定批准真实基准费率及折扣，核查具体服务的价格监管适用性及经济合理性。本草案不证明已有获批价目表或成本测算。
